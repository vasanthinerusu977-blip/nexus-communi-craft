# Government Comms Hub

Build a GenNexus web app using the attached HTML as the working-file reference. First inspect and repair any broken/truncated JavaScript. Upgrade the prototype into a source-aware government communications workspace. Enable Lovable Cloud first because this needs saved version history, uploads, and AI-backed processing. Implement: (1) uploads and pasted content; analyze supported documents and provide clear source-analysis/limitations; (2) AI-backed generation of polished, structured outputs based strictly on uploaded/pasted content and selected audience/tone/language/detail/objective: government-style LinkedIn post, X/Twitter thread with separate 280-character-safe posts and a consistent official-comms sequence, formal advisory with appropriate non-sensitive classification/distribution placeholders, infographic brief plus rendered downloadable visual, concise executive summary, slide-by-slide presentation outline with speaker notes, report/article, and a video production package; (3) video package must be a downloadable production brief, NOT an MP4, including storyboard, timed shot list, narration, on-screen copy, visual directions, and valid SRT subtitles. Make each component exportable individually and as a bundle where feasible; be transparent that actual MP4/video generation and external-video analysis require a connected video model/service; (4) after generation, a satisfaction loop: satisfied finalizes; not satisfied asks exactly what to change and allows iterative regenerations until user confirms satisfaction; store revisions and let users compare/restore prior versions; (5) an assistant chatbot which answers broader questions about the product and its use. Do not invent founder/founding details. For questions with unknown organizational facts say the information has not been configured, and offer an admin-editable knowledge base/about section; (6) add clear content-safety/review cues: outputs are drafts requiring authorized review, and avoid claims of real NTRO affiliation. Use professional government-inspired styling but do not impersonate NTRO. Build a complete functional web app, not only static templates.
